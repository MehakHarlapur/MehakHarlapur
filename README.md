**AI-powered research assistant that allows users to upload multiple documents, ask questions, generate summaries, compare documents, and create research reports using Retrieval-Augmented Generation.**

### 🔹 Key Features

- 📄 Upload multiple PDF, DOCX & TXT documents
- 🔍 Hybrid Retrieval using Semantic Search + BM25
- 🧠 Google Gemini-powered responses
- 📚 ChromaDB Vector Database
- 🎯 Cross-Encoder Re-ranking
- 📝 Automatic Executive Summaries
- 📊 Multi-Document Comparison
- 💬 Question Answering over documents
- 📑 Research Report Generation
- 🎙️ Voice Input Support
- 📥 PDF Report Export
- 🎨 Modern Streamlit Interface

### 🛠️ Technologies

`Python` • `LangChain` • `Google Gemini` • `ChromaDB` • `Streamlit` • `Sentence Transformers` • `BM25`

### ⭐ Highlights

- Built an end-to-end RAG pipeline for multi-document research.
- Combined semantic and keyword-based retrieval for better document search.
- Implemented Cross-Encoder re-ranking to improve retrieval relevance.
- Generated AI-powered answers and summaries grounded in uploaded documents.
